QuicklyzXD Mic Volume Lock
Version 1.0 - Windows 10 / 11 (64-bit)
by QuicklyzXD

โปรแกรมพกพา (Portable) ใช้งานจาก .exe ได้เลย ไม่ต้องติดตั้ง ไม่ต้องใช้ PowerShell หรือ .NET เพิ่ม

วิธีใช้
1. เก็บไฟล์ QuicklyzXD_Mic_Volume_Lock.exe ไว้ในโฟลเดอร์ถาวร เช่น C:\Tools\QuicklyzXD\
2. ดับเบิลคลิกไฟล์ .exe
3. เลือกไมโครโฟนจากรายการด้านบน
   - "ค่าเริ่มต้นของ Windows": ล็อกไมค์บันทึกเสียงหลัก และตามอุปกรณ์เริ่มต้นที่เปลี่ยนไป
   - "ค่าเริ่มต้นสำหรับการโทร": ล็อกไมค์สำหรับ Communications
   - เลือกชื่ออุปกรณ์: ล็อกเฉพาะไมโครโฟนที่เลือก
4. เลื่อนแถบตั้งระดับเสียง เช่น 85%
5. ทำเครื่องหมาย "ล็อกเสียงไมค์ (เปิด/ปิด)"
6. หากต้องการให้โปรแกรมเปิดเองเมื่อเข้าสู่ Windows ให้ทำเครื่องหมาย "เปิดใช้งานอัตโนมัติพร้อม Windows"

การทำงาน
- โปรแกรมตรวจระดับเสียงไมโครโฟนทุก 350 มิลลิวินาที และปรับกลับเมื่อมีสิ่งอื่นเปลี่ยนระดับเสียง
- กด X หรือย่อหน้าต่างแล้วโปรแกรมจะทำงานต่อในไอคอน System Tray (ข้างนาฬิกา)
- คลิกไอคอน Tray เพื่อเปิดหน้าต่าง หรือคลิกขวาแล้วเลือก "ออกจากโปรแกรม" เพื่อปิดจริง
- เปิด .exe ซ้ำขณะโปรแกรมกำลังทำงานอยู่ จะเปิดหน้าต่างเดิม
- ถ้าเสียบ/ถอดอุปกรณ์ กด "รีเฟรช" เพื่ออัปเดตรายการไมค์

ข้อควรทราบ
- ต้องปล่อยให้โปรแกรมทำงานอยู่จึงจะล็อกเสียงได้
- ควบคุมระดับ Microphone ของ Windows (Core Audio) ไม่ได้ยกเลิก Auto Gain, Noise Suppression หรือ Sensitivity ของแต่ละแอป เช่น Discord
- ถ้าแอปใช้ไมค์คนละอุปกรณ์ ต้องเลือกไมค์ให้ตรง
- ค่าจะถูกบันทึกไว้ที่ %APPDATA%\QuicklyzXD\MicVolumeLock\settings.json
- การเปิดพร้อม Windows ใช้ Registry HKCU Run ไม่ต้องใช้สิทธิ Administrator
- ถ้าเปิดพร้อม Windows แล้ว ไม่ควรย้ายตำแหน่งไฟล์ .exe โดยไม่เปิดโปรแกรมใหม่เพื่ออัปเดตเส้นทาง
- โปรแกรมยังไม่ได้ลงลายเซ็นดิจิทัล (code signing); บางเครื่องอาจเตือน SmartScreen
- รุ่นนี้คอมไพล์เป็น Windows .exe แล้ว แต่ยังไม่ได้ทดสอบเปิดใช้งานบนเครื่อง Windows จริง

วิธีลองตรวจการทำงาน
Windows Settings > System > Sound > Input > เลือกไมค์ > ปรับ Input volume ลงขณะเปิด Lock
โปรแกรมควรดึงกลับสู่ค่าที่เลือกภายในประมาณ 0.35-1 วินาที (ขึ้นกับ Windows/ไดรเวอร์)

การถอนโปรแกรม
1. คลิกขวา Tray > ออกจากโปรแกรม
2. ยกเลิกติ๊กเปิดพร้อม Windows ก่อน (หากเปิดไว้)
3. ลบ .exe และโฟลเดอร์ค่าตั้งค่าใน %APPDATA%\QuicklyzXD\MicVolumeLock เมื่อไม่ต้องการใช้

แจกจ่ายไฟล์ .exe ได้ แนะนำให้ส่ง ZIP ต้นฉบับจากแหล่งที่เชื่อถือได้
